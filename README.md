# Fullstack · Livrer une évolution et défendre ses choix — élève

**4 h 30 · Java / React / Produit · PilotCrew.** Livrer la reprise d’une tentative après rechargement, traiter un incident et présenter un changement défendable en revue.

La séance réalise une tranche produit finie : retrouver une tentative après rechargement. Elle inclut planning, code Java/React, diagnostic, revue et restitution.

Ce support contient les tutoriels, mémos et espaces de réponse. Créer le code demandé dans `backend/` et `frontend/` ; le corrigé est privé et séparé. Les six séances forment un fil rouge progressif de **27 heures**, sans promesse de niveau senior.

## Préparer la séance

Avant cette séance, importer votre réalisation validée de `java-react-05-testing-eleve` dans votre nouvelle copie `java-react-06-product-eleve`. Reprendre backend/, frontend/ et scripts/ lorsqu’ils existent, ainsi que leurs configurations et lockfiles. Exclure .git/, target/, node_modules/, dist/, caches et sorties privées. Garder les documents de ce nouvel atelier. Noter le commit de provenance et exécuter les contrôles disponibles avant le début des 270 minutes.
